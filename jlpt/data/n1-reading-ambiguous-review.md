# N1 읽기 감사 `ambiguous` 검토표

`n1-reading-audit.csv`의 `ambiguous` 항목을 사람이 보기 쉽게 원인별로 정리한 문서다. 긴 예문 전체 대신 표제어가 실제 사용된 부분만 표시했다.

## 결론

- 현재 `ambiguous` 항목에서는 **지정 읽기와 명확히 충돌하는 예문을 발견하지 못했다.**
- 대부분 표제어의 `～`, 괄호 속 용법 메모, 복수 한자 표기를 감사 스크립트가 해석하지 못해 발생했다.
- 아래 표에서 `정상`은 예문의 실제 표기와 읽기가 암기 대상 읽기를 사용한다는 뜻이다.
- 188번 `摩する / さする`은 `ambiguous`가 아니라 `target-not-found`지만, `摩った / さすった`로 올바르게 활용되므로 수정하지 않는다.

## 후속 처리 권장 사항

1. 위 항목은 현재 예문을 수정하지 않는다.
2. 감사 스크립트에서 괄호 메모 제거, `～` 접사 검사, 복수 표기 분리를 지원하면 대부분 자동으로 `pass-*` 처리할 수 있다.
3. 스크립트 개선 전까지 이 문서를 현재 `ambiguous` 항목의 수동 검토 근거로 사용한다.
